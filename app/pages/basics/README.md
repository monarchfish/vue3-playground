# CH1 Vue 3 基礎語法

從模板語法與響應式 API 出發，建立 Vue 3 Composition API 的基本功。每頁皆含互動範例，可邊讀邊操作。

## 頁面列表

| 檔案 | 標題 |
|------|------|
| `index.vue` | 章節總覽 |
| `template-syntax.vue` | 模板語法 |
| `reactivity.vue` | 響應式 |
| `computed-watch.vue` | Computed & Watch |
| `conditional-loop.vue` | 條件與迴圈（v-if & v-for） |
| `event-binding.vue` | 事件處理 |
| `form-binding.vue` | 表單綁定 |

## 核心概念

- **模板語法**：插值 `{{ }}`、指令 `v-bind` / `v-on`、JavaScript 表達式
- **響應式**：`ref`、`reactive`、`toRefs`、響應式物件的存取與解構
- **衍生資料**：`computed` 快取計算、`watch` / `watchEffect` 副作用偵聽
- **條件與列表**：`v-if` / `v-show`、`v-for` 與 `key` 的使用時機
- **事件**：`@click` 修飾符（`.stop`、`.prevent` 等）、方法綁定
- **表單**：`v-model` 雙向綁定、checkbox / radio / select 各種控制項
