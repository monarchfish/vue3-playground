# CH8 生態系

介紹 Vue / Nuxt 周邊工具與框架特色：VueUse 工具集、Nuxt 內建能力，以及表單驗證實務。

## 頁面列表

| 檔案 | 標題 |
|------|------|
| `index.vue` | 章節總覽 |
| `vueuse.vue` | VueUse 工具集 |
| `nuxt-features.vue` | Nuxt 特色功能 |
| `form-validation.vue` | 表單驗證 |

## 核心概念

- **VueUse**：`@vueuse/core` 常用 composables（`useStorage`、`useDark` 等）
- **Nuxt 特色**：自動匯入、檔案式路由、`useRuntimeConfig`、layouts / middleware
- **表單驗證**：即時驗證、錯誤訊息顯示、與 v-model 整合的模式

本章內容與 CH10 實戰專案（筆記工具的 `useStorage`、電商的表單驗證）相互呼應。
